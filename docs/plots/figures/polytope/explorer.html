Height is evidence depth, not a third balance parameter. Failed coordinates rise to log₂(n + 1), where n is the smallest counterexample size observed; survivors rise to the experiment’s maximum tested size.

The endpoint morph uses α = 1/(Δ + 1) and β = 1 − 1/Γ. For Δ > 0 and Γ > 1, this mapping is continuous and reversible, with Δ = (1 − α)/α and Γ = 1/(1 − β). The endpoint therefore contains exactly the same parameter pairs and preserves their topology, but not distances, angles, area, or convexity. Intermediate slider positions are only an animation between the two exact coordinate charts.
